# 🤖 Telegram-бот «Югра-Гид» (Docker Edition)

Проект интерактивного гида по ХМАО-Югре, упакованный в Docker-контейнер для работы на серверах.

## 🚀 Как запустить на Arch Linux

### 1. Сборка образа

Откройте терминал в папке проекта и соберите образ:

```bash
sudo docker build -t ugra-gid-bot .

2. Запуск контейнера

Запустите бота в фоновом режиме с поддержкой цвета и TTY:
Bash

sudo docker run -d -it --name my-bot ugra-gid-bot

Флаги -it и -d позволяют боту работать в фоне, сохраняя возможность вывода цветных логов.
📊 Мониторинг логов (в реальном времени)

Чтобы увидеть, что делают пользователи в боте прямо сейчас (с цветовой индикацией):
Bash

sudo docker logs -f my-bot

Для выхода из режима просмотра нажмите Ctrl+C.
🛠 Полезные команды Docker

    Остановить бота: sudo docker stop my-bot

    Запустить снова: sudo docker start my-bot

    Удалить контейнер: sudo docker rm -f my-bot

    Посмотреть все запущенные контейнеры: sudo docker ps

🎨 Цветовая схема логов

    Зеленый: Системные уведомления (старт, загрузка файлов).

    Розовый фон: Сообщения от пользователей (кто, когда и что нажал).

    Синий фон: Ответы бота пользователю.

    Красный: Ошибки (проблемы с базой данных или сетью).
```
